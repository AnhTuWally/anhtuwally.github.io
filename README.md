# anhtuwally.github.io

Personal landing page for **Anh Tu** (`@AnhTuWally`) — mathematician, tool developer, and generalist with 5+ years of experience in animation pipeline development and IT infrastructure development & management.

Live site: [https://anhtuwally.github.io/](https://anhtuwally.github.io/)

## Structure

- `.nojekyll` — serves static assets directly on GitHub Pages without Jekyll processing
- `index.html` — main landing page
- `assets/css/style.css` — dark DCC-inspired stylesheet aligned with [pixelRef](https://anhtuwally.github.io/pixelRef/)
- `assets/js/main.js` — responsive navigation menu script
- `assets/img/favicon.svg` — geometric `AT` monogram favicon

## Local Preview

Run a local static server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in your browser.
